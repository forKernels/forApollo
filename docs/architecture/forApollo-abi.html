Purpose

forApollo is a universal state estimation, navigation, and guidance (GNC) engine: Kalman/extended/unscented/error-state filters, information and particle filters, batch/smoother orbit determination, state propagation (delegating ODE work to forMath), guidance and control laws (ZEM/ZEV, proportional navigation, Lambert, LQR, path following), a coordinate-frame catalog, and astrodynamics / environment / time utilities. The algorithms are domain-agnostic — "the state vector doesn't care what it represents." The same EKF that tracks a spacecraft tracks a robot-arm joint or a portfolio's drift.

Zortran Status

forApollo is the canonical reference model for the three-layer Zortran Wiring Contract. It implements the contract exactly:

  • Layer 1 — Fortran kernel (internal). Pure math in src/fortran/*.f90, bind(C, name="fa_*") using the internal-only fa_ prefix. No consumer binds an fa_* symbol; it lives inside the archive.
  • Layer 2 — Producer Zig export (the sole public C-ABI). src/zig/exports.zig declares 62 export fn forapollo_* (...) callconv(.c) functions. Each validates inputs, then dispatches to its Fortran kernel via an extern "c" fn fa_* declaration (in src/zig/fortran.zig). The math is never reimplemented in Zig.
  • Layer 3 — Consumer. Python (ctypes), Wintermute, and sibling libs link the prebuilt libforapollo.a and bind the Zig export forapollo_* only — never an fa_* Fortran symbol — and compile zero forApollo Zig.

Neither anti-pattern is present: no Anti-Pattern A (every forapollo_* export calls a real Fortran kernel — no pure-Zig math behind a Fortran-sounding name) and no Anti-Pattern B (Fortran exposes only the internal fa_* prefix; there is no bind(C, name="forapollo_*") for a consumer to bind directly).

The one gap: the winX86 target archive is not yet built (see Delivery). This is a build-coverage gap, not a wiring violation — the source and ABI are compliant on every target.

ABI Surface

62 public forapollo_* symbols, all defined in src/zig/exports.zig and all backed by an identically named fa_* Fortran kernel. All matrices cross the C ABI as flat 1-D row-major arrays (P(n*n) covariance, F(n*n) dynamics Jacobian, H(m*n) measurement Jacobian). Estimator/guidance routines return a status via the trailing info out-pointer (0=ok, 1=diverged, 2=singular, 3=invalid input, 4=convergence failure, 5=integration failure). The full machine-readable list is in forApollo-abi.tsv.

Note: the Fortran kernel layer is broader than the public surface — 114 fa_* kernels exist, of which 62 are currently exported. The remaining ~52 (e.g. fa_guidance_ddp, fa_astro_bielliptic, several fa_coords_*_matrix and fa_time_* conversions) are implemented and backed but not yet wrapped by a forapollo_* Layer-2 export.

Backing — Layer 2 → Layer 1

Every public forapollo_* Zig export reaches its Fortran kernel through an identically named extern "c" fn fa_* declaration. The math lives in Fortran; Zig validates and marshals. The exemplary mapping (the contract's worked example, verbatim from this repo): 

// LAYER 1 — src/fortran/forapollo_estimate.f90  (internal; fa_ prefix, no consumer binds it)
subroutine fa_kf_predict(n, x, P, F, Q, info) bind(C, name="fa_kf_predict")
    use iso_c_binding
    integer(c_int), value         :: n
    real(c_double), intent(inout) :: x(n), P(n*n)
    real(c_double), intent(in)    :: F(n*n), Q(n*n)
    integer(c_int), intent(out)   :: info
    ! ...the actual Kalman predict math...
end subroutine fa_kf_predict

// LAYER 2 — src/zig/exports.zig  (THE public C-ABI; ships in libforapollo.a)
pub export fn forapollo_kf_predict(
    n: i32, x: [*]f64, P: [*]f64, F: [*]const f64, Q: [*]const f64, info: *i32,
) callconv(.c) void {
    if (n <= 0) { info.* = 3; return; }   // validate (Zig)
    dispatch.kfPredict(n, x, P, F, Q, info); // -> extern fn fa_kf_predict (Fortran)
}

// LAYER 3 — consumer (Python ctypes / Wintermute / sibling)
//   binds forapollo_kf_predict; never sees fa_kf_predict.

Backing summary: all 62 exports are abi_owner = zig-export, backing = fortran:fa_<sym>. There are zero Anti-Pattern B symbols (no bind(C, name="forapollo_*") anywhere in src/fortran/) and zero Anti-Pattern A symbols (no pure-Zig math behind a forapollo_* name).
